# Data

[English](README.md) | [Chinese](README_zh.md)

This directory contains the released datasets and ESConv-derived profiles used by the INT system.

Paper: https://aclanthology.org/2025.emnlp-main.1245/

## NTConv Dataset (`ntconv/`)

`ntconv/` contains 1300 English narrative therapy dialogues generated by the INT framework.

Generation process, following paper Section 4.4:

1. Extract client profiles from ESConv, including emotion, problem, and situation.
2. Use GPT-4o to simulate the client based on the profile.
3. Let the simulated client interact with INT for 50 turns.
4. Annotate each turn with therapeutic stage and reflection level.

Split: 1040 train / 260 test (80/20, no overlap).

## Format

Each file is a JSON list of 50 turns.

```json
{
  "round": 1,
  "client": "I feel overwhelmed...",
  "therapist": "That sounds heavy...",
  "stage": "Trust Building",
  "reflection_level": "Empathic Comforting"
}
```

The first turns may include extra source fields such as `user`, `answer_final`, `user_annotations`, `supporter_annotations`, and `user_cooperation`.

## ESConv Profiles (`esconv_profiles/ESConv.json`)

`ESConv.json` contains 1300 processed ESConv conversations used as client seeds for simulation.

Each item contains fields such as:

- `experience_type`
- `emotion_type`
- `problem_type`
- `situation`
- `survey_score`
- `dialog`
- seeker/supporter questionnaire fields

The INT simulator reads this file directly.

```bash
cd int
venv/bin/python simulate_client.py \
  --esconv ../data/esconv_profiles/ESConv.json \
  --profile-index 0 \
  --turns 35
```

## Real User Dialogues

Real user dialogues are not included in the current public directory.

If released later, they should be de-identified and documented before publication.
